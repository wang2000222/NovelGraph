# NovelGraph — Story Planning & Collaboration Platform

NovelGraph is a Java and Vue portfolio project for organizing characters, events, locations and relationships in a visual workspace.

## Capabilities

- Structured story data and an interactive relationship graph.
- Account sessions, tenant isolation, team membership and project permissions.
- Version checks, snapshots and restoration.
- Validated JSON import with preview, reference mapping, transactions and duplicate-submission handling.
- Subscription quotas, manually activated orders and an administration interface.
- Exports with author and reader views, including chapter-based reveals.

## Stack

Java 8, Spring Boot 2.7.18, MyBatis-Plus, MySQL, Flyway, Vue 3, TypeScript, Vite and Vue Flow.

The repository includes backend integration tests and frontend tests. See [setup instructions](SETUP.md) for local verification.

## Scope

This is a personal portfolio project, not a paid client case study. AI-assisted extraction uses copied prompts and user-imported responses; it does not call an AI provider directly. Subscription activation is manual and online payments are not integrated. A hosted demo, screenshots and video are still pending.

The implementation demonstrates patterns relevant to business dashboards, content platforms, membership systems and team collaboration tools.
