# 项目案例与演示脚本

## 中文案例介绍

NovelGraph 是面向小说创作场景的世界观与剧情管理平台，使用 Java / Spring Boot 实现后端，Vue 实现可视化编辑界面。用户可以管理人物、事件与关系，在团队空间中协作，并通过快照和版本检查减少误操作与修改覆盖。

后端重点包括租户与项目权限隔离、关联数据一致性、批量导入校验和事务回滚，以及套餐配额和订单幂等处理。前端提供关系图编辑、团队管理与运营后台。AI 提取使用提示词与 JSON 回答导入流程，订阅通过管理员人工开通。

这是个人作品展示，适合用于说明业务系统、内容管理与团队协作平台的开发能力。

## 三分钟演示顺序

1. 介绍问题：人物和事件散落在文档里，很难追踪关联。
2. 打开预先准备的虚构故事，展示人物、事件、地点及关系图。
3. 修改一个人物，调整图布局，展示保存与重新打开后的结果。
4. 展示快照；恢复前确认使用独立演示数据。
5. 展示团队成员与项目权限，用受限账号验证可访问范围。
6. 展示 AI 回答导入的预览、校验与确认，以及作者 / 读者导出。
7. 最后展示运营后台中的套餐和订单，解释人工开通边界。
